## 2. 技術要件

### バージョン指定（重要：必ずこのバージョンで実装すること）

- **Astro 7.x**（`pnpm create astro@latest` で最新を取得。2026年9月時点で 7.3.x）
- **Tailwind CSS v4.x**（`@tailwindcss/vite` プラグイン経由）
- **pnpm 11.x**（v12はRustへのフルリライト直後のため今回は採用しない）
- **Node.js 24 LTS**（pnpm 11 は Node.js 22 以上が必須）
- TypeScript（`strict: true`）

### Tailwind v4 の記法を厳守（v3の記法を絶対に使わない）

以下はすべて **v3の廃止された書き方**。生成してはいけない：
- ❌ `tailwind.config.js` にテーマを書く
- ❌ `@tailwind base; @tailwind components; @tailwind utilities;`
- ❌ `content: [...]` でスキャン対象を手動指定
- ❌ `postcss` / `autoprefixer` を依存に追加

正しいv4の書き方：
```css
/* src/styles/global.css */
@import "tailwindcss";

@theme {
  --color-rose-brand: #E0356B;
  --color-rose-deep:  #B72455;
  --color-rose-tint:  #FDF2F6;
  --color-ink:        #1C1F23;
  --color-ink-muted:  #5C6470;
  --color-line:       #E8E6E7;
  --font-sans: "Noto Sans JP", ui-sans-serif, system-ui, sans-serif;
  --font-display: "Figtree", ui-sans-serif, sans-serif;
}
```
色・余白・角丸は**必ず `@theme` のトークン経由**で使うこと。
コンポーネント内に生の hex 値（`#E0356B` 等）を直接書くことを禁止する。

### セットアップ手順

```bash
# プロジェクトは必ずLinux側のホーム配下に作る（/mnt/c 配下は禁止）
cd ~/projects
pnpm create astro@latest yui-lp -- --template minimal --typescript strict
cd yui-lp
pnpm add tailwindcss @tailwindcss/vite
```

`astro.config.mjs`:
```js
import { defineConfig } from 'astro/config';
import tailwindcss from '@tailwindcss/vite';

export default defineConfig({
  site: 'https://TODO.example.com',
  vite: { plugins: [tailwindcss()] },
  build: { inlineStylesheets: 'auto' },
});
```

### その他

- コンテンツは `src/data/*.ts` に構造化データとして分離（メニュー6種、選ばれる理由3つ、
  流れ4ステップ、FAQ、導入事例はすべて型付き配列にする）
- 画像は `astro:assets` の `<Image>` を使用。AVIF/WebP、`loading="lazy"`、
  FV画像のみ `loading="eager"` + `fetchpriority="high"`
- クライアントJSは IntersectionObserver によるスクロール表示のみ。
  UIフレームワーク（React/Vue/Svelte）のアイランドは**一切使わない**
- FAQは `<details>` / `<summary>` で実装（JSなし・アクセシビリティ標準対応）
- 依存を追加する際は必ず理由を述べ、承認を得ること。無断で
  アニメーションライブラリやUIキットを入れない
