# 修正依頼：ファーストビューのCTAボタンのレイアウト崩れ

## 現象

モバイル幅（〜639px）のファーストビューで、「無料で見積りを依頼する」と
「LINEで相談する」の2つのボタンが、**縦積みなのに横幅がコンテナの約50%しかなく、
右側に大きな余白が発生している**。

ボタンの直下にある注釈テキスト「現在準備中です。お急ぎの方は…」も同じ幅で
折り返しており、視覚的に不自然。

## 1. まず原因を特定する（対症療法を禁止）

`w-full` を足して見た目だけ直すのは禁止。以下の順で原因を特定し、
`docs/fix-log.md` に「何が原因だったか」を1〜2行で記録してから修正すること。

疑うべき箇所（可能性の高い順）：

1. **CTAブロックが、直上のバッジ用グリッド（`grid-cols-2`）の中に入ってしまっている**
   → グリッドの1セル＝50%幅を継承している。最有力
2. ボタンのラッパーに `sm:` 等の接頭辞なしで幅制約（`w-1/2`, `max-w-[50%]`,
   `basis-1/2`）が付いている
3. ボタンコンポーネント側にデスクトップ想定の固定幅が入っている
4. 親が `flex flex-wrap` で、`flex-col` と併用されて意図しない折り返しになっている

## 2. 目指すレイアウト（レスポンシブの定石）

| ブレークポイント | 挙動 |
|---|---|
| 〜639px（モバイル） | **縦積み・コンテナ幅いっぱい**。主CTAが上、副CTAが下 |
| 640px〜（sm以上） | **横並び・内容に応じた幅（hug）**、左揃え |

実装の基本形：

```astro
<div class="mt-8 flex flex-col gap-3 sm:flex-row sm:flex-wrap sm:items-center sm:gap-4">
  <CtaButton variant="primary"   class="w-full sm:w-auto">無料で見積りを依頼する</CtaButton>
  <CtaButton variant="secondary" class="w-full sm:w-auto">LINEで相談する</CtaButton>
</div>
```

### 守るべき条件

- ボタン自体は `inline-flex items-center justify-center` でラベルを中央寄せ。
  全幅になってもラベルが左に寄らないようにする
- 横並び時に**ボタンが横に伸びすぎないよう**、`sm:w-auto` で内容幅に戻す。
  `sm:flex-1` は使わない（幅がバラつき、長いラベル側だけ間延びする）
- タップ領域の高さは **最低48px**（`min-h-12`）を確保
- 縦積み時の間隔は `gap-3`（12px）程度。詰めすぎない
- ボタンとその上のバッジ群の間は `mt-8`（32px）以上あける

## 3. 注釈テキストの扱い

「現在準備中です。お急ぎの方はメールでご連絡ください」は、
**どのボタンに対する注釈なのかが現状わからない**。以下に直す。

- ボタン群の**外側・直下**に配置し、幅はコンテナ幅いっぱいにする（半端な折り返しをなくす）
- `text-sm text-ink-muted` で、ボタンより明確に弱いトーンにする
- 副CTAの補足であることが伝わる文言にする
  例：「※LINEアカウントは現在準備中です。お急ぎの場合はメールでご連絡ください。」

## 4. あわせて確認・修正する（同じ画面で見つかった問題）

### 4-1. CTAが1画面に3組ある

現在、スクロール位置に関わらず
①ヘッダー右上「無料で見積る」 ②FV内の2ボタン ③画面下部の固定バー
が**同時に見えている**。同じ行動を促すボタンが1画面に3つあるのは
ノイズであり、どれを押すべきか迷わせる。

修正方針：
- **下部固定バーは、FVのCTAが画面外に出てから表示する**
  （IntersectionObserver で FV内のCTAブロックを監視し、
  `isIntersecting === false` になったら固定バーをフェードインさせる）
- フッター直前のクロージングCTAが画面に入ったら、固定バーは再び隠す
- **ヘッダー右上のCTAはモバイル（〜639px）では非表示**にする
  （固定バーと役割が重複するため）。`hidden sm:inline-flex`

### 4-2. 機能しないCTAを主要導線に置かない

「LINEで相談する」は準備中で押しても何も起きない。押せるのに動かないボタンは、
ボタンがないことより体験を損なう。以下のいずれかに変更すること：

- **推奨**：LINEのURLが用意できるまで、副CTAを「メールで問い合わせる」に差し替える
  （`mailto:sendai.private.salon.yui@gmail.com`）
- 代替：ボタンを `disabled` にし、`aria-disabled="true"` と
  視覚的な非活性スタイル（不透明度・カーソル）を適用する

下部固定バーの「LINEで相談」も同じ扱いに揃えること。

## 5. 横展開

`CtaButton` は複数セクションで使い回している想定。**FVだけ直して終わりにしない。**

以下すべてで同じレイアウトルールが適用されているか確認し、崩れていれば直す：

- ファーストビュー
- 料金プランセクション直下
- クロージングCTAセクション
- 下部固定バー（ここは常に横2分割で全幅。上記ルールの例外として扱う）

## 6. 検証

修正後、以下の幅で目視確認し、結果を報告すること：

| 幅 | 確認内容 |
|---|---|
| 375px | ボタンが全幅、はみ出しなし、ラベルが1行に収まる |
| 390px | 同上 |
| 599px | まだ縦積み全幅であること（中途半端な幅にならない） |
| 640px | 横並びに切り替わり、ボタンが内容幅になること |
| 768px | 横並び、左揃え、不自然な余白がないこと |
| 1440px | ボタンが間延びしていないこと |

あわせて：
- キーボードの Tab でボタンにフォーカスでき、フォーカスリングが見えること
- `pnpm build` が警告なしで通ること
