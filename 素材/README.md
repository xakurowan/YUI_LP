## 注意

- 人物写真（hero-main / menu-01〜06）はストックフォトの可能性が高い。
  **印刷物のライセンスとWeb掲載のライセンスは別契約のことがある**ため、
  公開前に利用規約を確認すること。
- therapist.png は本人写真。掲載可否を本人に確認すること。
- アイコンPNGは背景白。CSSで `mix-blend-mode: multiply` を使うか、
  SVG（lucide等）へ置き換える方が軽量かつ高品質。
